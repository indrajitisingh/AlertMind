# 📊 SOC Dashboards

## Overview

AlertMind includes two dashboards developed using the Wazuh Dashboard to help Security Operations Center (SOC) analysts monitor alerts, identify attack patterns, and investigate security events efficiently.

---

# 1. Daily SOC Dashboard

The Daily SOC Dashboard provides a real-time overview of security events generated across monitored endpoints.

### Features

- Total Alerts
- Top Triggered Rules
- Top Agents
- Alerts Over Time

### Purpose

This dashboard enables SOC analysts to quickly understand the security posture of the environment by monitoring alert volume, identifying frequently triggered rules, tracking the most active endpoints, and observing alert trends over time.

---

# 2. MITRE ATT&CK Dashboard

The MITRE ATT&CK Dashboard maps security alerts to the MITRE ATT&CK framework, allowing analysts to understand attacker behavior through associated tactics and techniques.

### Features

- Top MITRE ATT&CK Techniques
- Top MITRE ATT&CK Tactics
- Total MITRE Alerts
- MITRE Alerts Over Time

### Purpose

This dashboard helps analysts identify which ATT&CK tactics and techniques are most frequently observed, monitor trends in MITRE-mapped alerts, and improve threat hunting and incident response activities.
